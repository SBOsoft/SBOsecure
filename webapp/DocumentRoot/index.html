How to use SBOsecure
What is SBOsecure?

A simple tool for sending private messages and files. Only the people you choose can open them, and they can check that the file really came from you. Everything runs in your browser: nothing is uploaded, and there is no account.

You have a pair of keys:

  • Public key: give it to anyone who wants to send you something.
  • Private key (inside your keyset file, protected by your password): keep it to yourself. It opens what others send you.

Typical workflow

  1. Create your keys once and save the keyset file.
  2. Swap public keys with the people you talk to and add them as contacts.
  3. Encrypt for a contact, then send them the .sbo.json file any way you like.
  4. They decrypt it with their own keys.
My Keys

Create new key:
enter a name, a password and an iterations number (600,000–1,000,000). Then download the keyset file straight away. Keys are lost when the page is closed.

Load key:
at the start of each session, pick your keyset file and enter the same password and number (the "secret number").

Public key downloads public.jwks.json. Share that file with contacts. Never share the Keyset file.

If you forget the password or the number, the key cannot be recovered.
Contacts

A contact is a name plus that person's public key. Click Add and load their public.jwks.json, or paste its contents.

Contacts are only kept while the page is open. Use Download all to save them, and Import to load them next time.

Get public keys from a channel you trust. If an attacker swaps the key, they can read what you send.

Encrypt
  1. Type a message or choose a file.
  2. Tick one or more recipients from your contacts.
  3. Click Encrypt, then download or share the .sbo.json file.

If your keys are loaded, the package is signed. Recipients who have you as a contact will see that it was signed by you.

You can't open a package you encrypted for someone else unless you also add yourself as a recipient.
Decrypt
  1. Load your keys in My Keys first.
  2. Paste the package content or load the .sbo.json file.
  3. Click Decrypt. Text is shown on screen; files can be saved.

The signature badge tells you about the sender:

  • Valid, signed by contact: it came from that contact and hasn't been changed.
  • Valid, signer not in your contacts: anyone can sign a package, so you can't tell who sent it. Add the sender as a contact using their public key to confirm it.
  • Invalid: the package was modified. Don't trust it.
  • No signature: you can't tell who sent it.

If decryption fails, click Show document details. It compares the key fingerprints the package expects with your loaded keys and suggests what went wrong.

Password Enc.

Encrypts text with just a password, so no keys or contacts are needed. The recipient needs the package file, the password and the iterations number. Tell them the password some other way than the file, e.g. by phone.

Base64

Converts text to and from Base64. This is not encryption: anyone can decode it. Use it to move data through channels that only accept plain text.

Good to know
  • Refreshing or closing the page clears loaded keys and contacts. Save your files.
  • Keep your keyset file as safe as a password-manager file.
  • Uses your browser's built-in Web Crypto: AES-256-GCM, RSA-OAEP, RSASSA-PKCS1-v1_5 and PBKDF2-SHA-256.
