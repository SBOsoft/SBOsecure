SBOsecure allows you to encrypt/decrypt and sign/verify files and text easily, using only functionality provided by modern browsers. It is technically secure enough and also easy to use for ordinary people.
All processing takes place in your browser, locally. No data leaves your browser, there is no server side component or code.
You can download the source files from github and deploy it on your own servers, devices. You just need to access the web page over a https connection.
It may not be suitable for use with large files, but files up to 10-20MBs should work fine on a recent device.
See SBOsecure for latest updates and documentation
